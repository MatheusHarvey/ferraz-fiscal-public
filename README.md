# Ferraz Fiscal

Ferramenta local de auditoria cívica das finanças do município de Ferraz de Vasconcelos — SP.

## Objetivo
Cruzar dados de fontes públicas (SICONFI, TCE-SP, Portal da Transparência Federal)
para identificar gaps, inconsistências e possíveis irregularidades nas finanças municipais.

## Fontes de dados
- SICONFI / STN — relatórios fiscais obrigatórios
- TCE-SP / SAGRES — tribunal de contas estadual
- Portal da Transparência Federal — transferências da União
- IBGE — dados socioeconômicos
- DATASUS — indicadores e gastos de saúde

## Código IBGE do município
`3515103`

Python 3.11 · DuckDB · Streamlit · Pandas · Plotly
